# Phase 0 — Nền tảng công cụ & tư duy

Repo luyện tập giai đoạn 0 trong lộ trình học lập trình.
Mục tiêu: **không bị kẹt vì môi trường** trước khi bước vào HTML/CSS/JS.

## Cấu trúc

| Thư mục | Nội dung |
|---|---|
| `01-concepts/` | Lý thuyết cần đọc: Terminal, VS Code, Git, tư duy |
| `02-practice/` | Bài thực hành, drill, sandbox để làm tay |

## Cách học

1. Đọc file trong `01-concepts/` theo thứ tự:
   `01-terminal` → `02-vscode` → `03-git-github` → **`03b-github-setup/`** (đọc `README.md` trước) → `04-mindset`.
2. Làm hết bài trong `02-practice/` tương ứng.
3. Đánh dấu vào `CHECKLIST.md` khi xong.
4. **Commit sau mỗi phần** — bản thân việc commit cũng là kỹ năng cần luyện.

## Yêu cầu môi trường

- [ ] Terminal
  - macOS/Linux: Terminal có sẵn
  - Windows: **Git Bash** (cài kèm [Git for Windows](https://git-scm.com/download/win)) — khuyến nghị; hoặc WSL
- [ ] VS Code
- [ ] Git
- [ ] Tài khoản GitHub

> 🪟 **Dùng Windows?** Toàn bộ lệnh trong tài liệu được viết cho **Git Bash**. Không dùng Command Prompt (`cmd`) vì `cmd` không hiểu `~`, `ls`, `touch`...
> Chưa có Git Bash → cài **Git for Windows** trước, rồi quay lại làm bài.

> ⚠️ Không cần giỏi ngay. Cần **làm tay** — đọc 5 phút, gõ 30 phút.
