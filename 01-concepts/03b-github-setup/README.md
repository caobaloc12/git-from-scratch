# Thiết lập GitHub — Hướng dẫn từng bước

> Dành cho bạn **chưa có tài khoản GitHub** và **chưa từng đưa code lên mạng**.
> Làm tuần tự từng chặng. Xong chặng nào, tick vào ô chặng đó.

## Quy tắc

- **Đừng đọc hết một lượt**. Mở 1 file → làm → kiểm tra → mới sang file tiếp theo.
- Mỗi chặng có **checkpoint ✅** ở cuối. Không đạt checkpoint thì **không đi tiếp**.
- Kẹt thì xem **bảng lỗi thường gặp** ở cuối mỗi file.

## Ký hiệu dùng trong tài liệu

- 👁️ **Bạn sẽ thấy** — mô tả màn hình / nút / thông báo để nhận ra mình đang đúng chỗ.
- ✅ **Checkpoint** — dấu hiệu phải đạt để đi tiếp.
- ⚠️ — cảnh báo chỗ dễ sai.
- 🆘 — lỗi hay gặp.
