# VS Code

## Extension cơ bản nên cài

- **Prettier** — format code tự động
- **ESLint** — bắt lỗi JS (cài khi học JS)
- **Live Server** — chạy HTML nhanh
- **GitLens** — xem lịch sử git ngay trong editor
- **Vietnamese Language Pack** (nếu muốn)

## Phím tắt cần nhớ

| Shortcut | Tác dụng |
|---|---|
| `Ctrl/Cmd + P` | Mở nhanh file |
| `Ctrl/Cmd + Shift + P` | Command palette |
| `Ctrl/Cmd + B` | Ẩn/hiện sidebar |
| `Ctrl/Cmd + /` | Comment dòng |
| `Ctrl/Cmd + D` | Chọn từ tiếp theo giống vậy |
| `Alt + ↑/↓` | Di chuyển dòng |
| `Ctrl/Cmd + ` ` ` | Mở terminal tích hợp |
| `F2` | Đổi tên biến toàn project |

## Terminal tích hợp

Mở bằng `` Ctrl + ` ``. Đứng đúng thư mục project → gõ lệnh Git/npm ngay tại đây.

## Settings nên bật

- Format on save (Prettier)
- Auto save: `onFocusChange`
- Tab size: `2` (cho JS/Web)
